NFC Bridge example

This page loads nfc-bridge.js from a CDN and wires it to a button. Open it in Chrome on Android, tap the button, then hold an NFC tag to the back of your phone.

The code

Here's all you need to add to a page:

<script src="https://web-nfc-fawn.vercel.app/nfc-bridge.js"></script>

<button id="scan">Scan NFC tag</button>

<script>
  NfcBridge.bind(document.getElementById('scan'), {
    getAuthData: () => ({ session: 'demo_session', nonce: 'demo_nonce' }),
    onResult: result => console.log(result),
    onError: err => console.error(err.code, err.message)
  });
</script>
